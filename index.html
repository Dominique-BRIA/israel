Domaine : texte

ChatGPT

L'outil avec lequel on discute en langage naturel.

Qu'est-ce que ChatGPT ?

ChatGPT est un outil d'intelligence artificielle avec lequel on peut discuter en langage naturel : on lui écrit une question ou une consigne comme on parlerait à un humain, et il répond avec du texte. Il a été conçu pour comprendre le langage et produire des réponses utiles.

Exemple

Prompt

Explique le fonctionnement d'Internet à un élève débutant en informatique.

Réponse de l'IA

Imagine un réseau de routes qui relie des milliards d'ordinateurs à travers le monde : c'est Internet. Chaque ordinateur peut envoyer des messages à n'importe quel autre. Quand tu regardes une page web, ton ordinateur demande cette page à un autre ordinateur, appelé serveur, qui la lui envoie. Le contenu voyage en petits paquets, comme des lettres à la poste, puis il est réassemblé à l'arrivée. Le navigateur est le logiciel qui lit ces pages et te les affiche. Grâce à ce gigantesque réseau, on peut envoyer des messages, regarder des vidéos ou consulter des informations depuis presque partout dans le monde.

Limites

  • Peut produire des informations incorrectes — il « invente » parfois.
  • Les réponses doivent toujours être vérifiées.
  • La qualité de la réponse dépend de la qualité de la question posée.

Domaine : image

Nano Banana

L'outil qui crée et modifie des images à partir d'instructions.

Qu'est-ce que Nano Banana ?

Nano Banana permet de créer ou modifier des images à partir d'une simple description écrite, appelée prompt. On décrit ce qu'on veut voir — un objet, un décor, un style — et l'outil dessine l'image correspondante. Il peut aussi reprendre une image existante et la transformer.

Démonstration

Prompt

Crée une classe Java Product avec un identifiant, un nom, un prix et une quantité. Explique ensuite le code simplement.

Product.java Java 
public class Product {

    // Les attributs : les informations mémorisées par un produit
    private int identifiant;
    private String nom;
    private double prix;
    private int quantite;

    // Le constructeur : comment créer un nouveau produit
    public Product(int identifiant, String nom, double prix, int quantite) {
        this.identifiant = identifiant;
        this.nom = nom;
        this.prix = prix;
        this.quantite = quantite;
    }

    // Les getters : lire les informations
    public int getIdentifiant() { return identifiant; }
    public String getNom()      { return nom; }
    public double getPrix()     { return prix; }
    public int getQuantite()    { return quantite; }

    // Les setters : modifier les informations
    public void setPrix(double prix)       { this.prix = prix; }
    public void setQuantite(int quantite)  { this.quantite = quantite; }

    // Une méthode « métier » : la valeur totale du stock
    public double valeurStock() {
        return prix * quantite;
    }

    // Un affichage lisible pour un humain
    @Override
    public String toString() {
        return nom + " (" + quantite + " x " + prix + " FCFA)";
    }
}

L'explication du code, simplement

  • La classe Product est un modèle (un « plan ») : elle décrit ce qu'est un produit, mais elle n'est pas un produit en soi. C'est à partir d'elle qu'on fabriquera de vrais produits.
  • Ses quatre attributs sont private : on ne peut pas les modifier directement de l'extérieur. C'est le principe d'encapsulation.
  • Le constructeur (méthode qui porte le nom de la classe) indique comment créer un produit en donnant ses valeurs de départ.
  • Les getters et les setters sont les portes d'entrée contrôlées : ils permettent de lire et de modifier proprement les informations.
  • valeurStock() est une méthode « métier » : elle calcule quelque chose d'utile (prix × quantité), et toString() renvoie un affichage lisible.

Limites

  • Le code produit peut contenir des erreurs.
  • Une solution proposée n'est pas toujours la plus optimale.
  • Il faut toujours tester le code avant de l'utiliser.
  • L'utilisateur doit comprendre ce qu'il utilise.

Outil : ChatGPT Domaine : texte

Prompt

Explique ce qu'est Internet à un élève de Terminale.

Réponse de l'IA

Internet est un réseau mondial : des millions de machines (ordinateurs, serveurs, téléphones) reliées par des câbles sous-marins, de la fibre optique et des liaisons satellites. Les échanges y sont découpés en paquets qui transitent selon des règles communes, les protocoles TCP/IP. Quand tu tapes une adresse dans ton navigateur, une requête part vers le serveur qui héberge le site ; le serveur renvoie les fichiers de la page (HTML, CSS, JavaScript) et le navigateur les assemble pour l'afficher. Ton fournisseur d'accès (FAI) est la porte d'entrée qui te connecte à ce réseau.

Ce que nous observons

L'IA a employé un vocabulaire technique — protocoles TCP/IP, serveur, FAI, paquets — adapté à un niveau de Terminale. Comparez avec la réponse « débutant » de la fiche ChatGPT : c'est le même sujet, mais l'explication change complètement de niveau.

Ce que cette expérience nous apprend : l'IA peut adapter son explication au niveau de la personne qui pose la question.

Outil : Nano Banana Domaine : image

Prompt

Ce que nous observons

L'IA a compris la consigne de modification : elle a conservé le camion et remplacé son environnement. Mais regardons bien les détails — les reflets, les lettres du logo — tout n'est pas parfait. Une consigne plus précise (« garde les roues telles quelles », « police verte en majuscules ») donne généralement un résultat plus fidèle.

Ce que cette expérience nous apprend : une modification d'image réussie demande une consigne précise : quel élément garder, quoi changer, dans quel style.

Outil : Claude Domaine : programmation

Prompt

Écris une fonction JavaScript qui calcule la moyenne des notes d'un élève, puis explique-la.

moyenne.js JavaScript 
function moyenne(notes) {
  if (notes.length === 0) {
    return 0; // pas de note : la moyenne vaut 0
  }
  let somme = 0;
  for (const note of notes) {
    somme += note;
  }
  return somme / notes.length;
}

// Exemple d'utilisation :
// moyenne([12, 15, 9]) renvoie 12

Ce que nous observons

L'IA a prévu le cas particulier de la liste vide, choisi des noms de variables clairs, commenté le code et ajouté un exemple d'utilisation. Le code paraît correct… mais il faut encore le tester : c'est la règle numéro un avec du code généré par IA.

Ce que cette expérience nous apprend : l'IA peut produire du code propre et commenté — mais c'est à l'utilisateur de le vérifier et de le tester.

Bilan

Ce que nous avons appris

Cinq observations à retenir de tout ce travail.

  1. L'IA peut comprendre des instructions

    Nous pouvons donner une consigne en langage naturel, comme à un humain.

  2. L'IA peut produire différents types de contenus

    Texte, image ou code : cela dépend de l'outil utilisé et de la tâche demandée.

  3. La qualité de la demande est importante

    Une consigne précise permet généralement d'obtenir un résultat plus adapté.

  4. L'IA n'est pas infaillible

    Elle se trompe, elle invente : les résultats doivent être vérifiés.

  5. L'utilisateur reste important

    L'IA est un outil d'assistance : l'utilisateur doit comprendre et contrôler le résultat.

Attention

Les limites de l'intelligence artificielle

« Une réponse produite par une IA n'est pas automatiquement une réponse correcte. »
  • Des erreurs sont possibles, même dans un ton très sûr.
  • Des informations peuvent être inventées ou incorrectes.
  • La consigne peut être mal interprétée.
  • Les résultats visuels peuvent être imparfaits.
  • Le code généré peut contenir des erreurs.
  • Vérifier les résultats reste indispensable.

Utilisée avec esprit critique, l'intelligence artificielle est un formidable assistant. La clé, c'est de rester celui qui réfléchit.
